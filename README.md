## Provenance

This repository contains a snapshot import of the ISLAMU Event platform:

- **Source repository:** [islamu-ngo/Event](https://github.com/islamu-ngo/Event) (public, GNU AGPL v3)
- **Imported snapshot:** commit `5cfa996b` (branch `develop`, 2026-07-14), tracked files only
- **License continuity:** the source is AGPL v3 and this repository is AGPL v3; the import
  preserves the original license terms without modification.
- **Divergence:** islamu.ngo adapts the platform as the single first-party ISLAMU deployment
  (deployment identity, Keycloak topology, InteractiveServer rendering). Intentional
  divergences from the source platform are recorded in
  `dev/active/init-import-islamu-event/` and, once created, `dev/report/EVENT_REFERENCE_ALIGNMENT.md`.
